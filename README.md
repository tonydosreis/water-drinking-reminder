# Water Drinking Reminder
Arduino pro mini project of a water drinking reminder device that is attached to a water bottle.

### Electrical Components
- Arduino pro mini 3.3V 8 mHz
- [Battery holder for 20mm coin battery](https://www.digikey.com/en/products/detail/mpd-memory-protection-devices/BA2032SM/257743?so=97387088&content=productdetail_row&mkt_tok=MDI4LVNYSy01MDcAAAGf6mIdEVHyXeYPe93rt9EBuivVbRmf-UKU_09h0lzxb7CBw6wzBukeALZzUiuuf2GXodaSrKmUcikDKyoOvTvWpsqIdMshyuNo5GOH2eNsSzo)
- 3V 20mm lithium coin battery
- [Tilt switch](https://www.digikey.com/en/products/detail/comus-international/CW1300-1/7497018?so=97387088&content=productdetail_row&mkt_tok=MDI4LVNYSy01MDcAAAGf6mIdEUdBDwxzeJH59ISpKLhtU15F-aw93oG77lAWRXrlV7XIgcOf3nAWsaNzTb4XF8q184FtvkNf8ZBoMJIMu2Ypd_GrINugLIY9wQ0iecw)
- Red LED
- 2kΩ resistor
